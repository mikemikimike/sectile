# @sectile/form API

@sectile/form의 공개 import 경로를 한 곳에서 확인합니다.

사용 흐름과 예시는 [@sectile/form 가이드](/ko/packages/form)에서 먼저 확인하세요. 이 페이지는 정확한 공개 import 경로를 찾는 레퍼런스입니다.

## 설치

```sh
pnpm add @sectile/form
```

## 공개 import 경로

| Import | 관련 레퍼런스 |
| --- | --- |
| `@sectile/form` | 패키지 공개 entry point |
| `@sectile/form/error` | 패키지 공개 entry point |
| `@sectile/form/path` | 패키지 공개 entry point |
| `@sectile/form/values` | 패키지 공개 entry point |
| `@sectile/form/state` | 패키지 공개 entry point |
| `@sectile/form/schema` | 패키지 공개 entry point |

`package.json`도 tooling용 공개 export로 제공됩니다.
