# 가이드

사용할 컴포넌트나 패키지를 이미 골랐고, 애플리케이션에서 구체적인 작업을 해결해야 할 때 이 가이드에서 시작합니다.

## UI 기본

- [스타일 적용](/ko/guide/styling) — 안정적인 part와 state 속성으로 제품 디자인 시스템을 적용합니다.
- [모션](/ko/guides/motion) — reduced motion을 지키면서 팝업 presence, 펼침 indicator, checked 상태, Drawer swipe를 애니메이션합니다.
- [Floating 요소](/ko/guide/positioning) — Popover, Select, Menu, Tooltip을 anchor 주변에 배치합니다.
- [상태 제어](/ko/guide/state-ownership) — 컴포넌트 계약을 바꾸지 않고 애플리케이션 상태가 값을 소유하게 합니다.

## 작업별

- [폼](/ko/packages/form) — 필드, 검증, 제출, 초기화, 사용자 정의 컨트롤.
- [날짜와 시간](/ko/packages/temporal) — 날짜, 시각, 범위, 달력, picker.
- [가상 목록](/ko/packages/virtual) — 큰 목록과 레이아웃을 렌더링하면서 스크롤 위치를 유지합니다.
- [표와 그리드](/ko/packages/tabular) — table, grid, tree-grid 데이터 상호작용.
- [차트](/ko/packages/chart) — line, scatter, bar, heatmap, pie, donut 차트.

## 실행 환경

- [Vue](/ko/packages/vue) — Vue 컴포넌트와 composable.
- [DOM](/ko/packages/dom) — 직접 생성하고 스타일링하는 브라우저 element.
- [터미널](/ko/packages/terminal) — 터미널 인터페이스.

정확한 식별자와 타입은 [API 레퍼런스](/ko/api/)에서 찾습니다.
