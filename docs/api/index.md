# API Reference

Use this area when you know what you want to build and need an exact public identifier, input, event, slot, type, or package export.

## Components

Open [Component API](/api/components/) to look up props, events, slots, public types, part selectors, and keyboard behavior. Use the [component catalog](/components/) when you want runnable examples first. Both surfaces are generated from the same checked-in public contracts, so names and types stay aligned with the package surface.

## Package APIs

The package reference is grouped by the public domain you import:

- [`@sectile/core`](/api/core)
- [`@sectile/form`](/api/form)
- [`@sectile/temporal`](/api/temporal)
- [`@sectile/virtual`](/api/virtual)
- [`@sectile/tabular`](/api/tabular)
- [`@sectile/chart`](/api/chart)
- [`@sectile/dom`](/api/dom)
- [`@sectile/terminal`](/api/terminal)
- [`@sectile/vue`](/api/vue)

The API area is the canonical lookup destination; usage and examples stay in Components and Guides.
