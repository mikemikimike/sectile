# @sectile/virtual API

@sectile/virtual의 공개 import 경로를 한 곳에서 확인합니다.

사용 흐름과 예시는 [@sectile/virtual 가이드](/ko/packages/virtual)에서 먼저 확인하세요. 이 페이지는 정확한 공개 import 경로를 찾는 레퍼런스입니다.

## 설치

```sh
pnpm add @sectile/virtual
```
